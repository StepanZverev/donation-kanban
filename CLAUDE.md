# Donation Kanban — договорённости

## Фронтенд (React + TS)

- Код должен легко читаться человеком: автор проекта дорабатывает фронт вручную.
- Сторонние библиотеки не добавляем без согласия: сначала предложить и объяснить, зачем она нужна.
- Drag-and-drop — на нативном HTML5 DnD.
- В компонентах обработчики (`handleX`) объявляются через `function` **после** `return`
  (function declarations всплывают, поэтому JSX может на них ссылаться).
- Запросы к API только через `src/api/`, логика доски — в `src/hooks/useCards.ts`.
- Стили — CSS Modules рядом с компонентом, цвета — CSS-переменные в `src/index.css`.

## Бэкенд (Python, FastAPI)

- Объяснения и комментарии простыми словами: бэкенд для автора менее привычен.
- SQLite через встроенный `sqlite3`, без ORM.
- Тесты: `pytest` в `backend/`.

## Процесс

- Каждый шаг — отдельная ветка и PR; перед пушем и PR спрашивать.
- Общение и комментарии в коде — на русском.
